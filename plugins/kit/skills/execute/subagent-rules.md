Leitura e busca: para ler arquivo use Read; para buscar, Grep/Glob. Bash só para git (log/blame/show/diff/status) e para os comandos do .claude/kit.json. Um comando por chamada de Bash: nunca encadeie com &&, ; ou |. Nunca cat/head/tail/sed/grep/find/ls via Bash, nem `cd <repo>;` no início (use git -C <repo>). Nunca entregue ao usuário comando com placeholder. Versões: o código segue as do perfil do stack (docs/stack.md) recebido no prompt; API que muda entre versões segue a documentação daquela versão ou o padrão do código existente do projeto, nunca a memória.
