# Adopt Sample
App de exemplo com telas, API de usuarios e textos em tres linguas.

## Comandos
- Testes: npm test
- Lint: npm run lint

## Regras
- Toda tela nova precisa de uma secao no manual (pasta manual/).
- Todo texto visivel vem de strings; nunca escreva texto fixo na tela.
- Nunca rode rm -rf no projeto.
